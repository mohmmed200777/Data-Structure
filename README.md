# Data Structures in C++

A comprehensive collection of fundamental Data Structures implemented from scratch using C++. This repository serves as a practical reference and portfolio for core software engineering concepts.

## 📂 Repository Structure

| Module | Description | Implementation Files |
| :--- | :--- | :--- |
| **ArrayList** | Dynamic sequential list based on arrays | `.h` / `.cpp` |
| **ArrayStack** | LIFO stack using static/dynamic arrays | `.h` / `.cpp` |
| **DoubleList** | Doubly linked list with bidirectional traversal | `.h` / `.cpp` |
| **LinkList** | Singly linked list core implementation | `.h` / `.cpp` |
| **LinkStack** | Linked-memory implementation of stack | `.h` / `.cpp` |
| **QueueArray** | FIFO circular queue implemented via arrays | `.h` / `.cpp` |
| **QueueLinked** | FIFO queue using dynamic nodes | `.h` / `.cpp` |
| **Recursion** | Classic recursive algorithms & problem solving | `.cpp` |
| **orderLink** | Sorted / ordered linked list variations | `.h` / `.cpp` |

## 🛠️ Built With
* **Language:** C++
* **Paradigm:** Object-Oriented Programming (OOP) & Template Classes
* **Tools:** Visual Studio Code, Git

## 🚀 How to Run
Clone the repository and compile any implementation with your preferred C++ compiler:

```bash
git clone [https://github.com/mohmmed200777/Data-Structure.git](https://github.com/mohmmed200777/Data-Structure.git)
cd Data-Structure
g++ -std=c++17 FolderName/*.cpp -o main
./main
```
